# references

Bibliografía, frameworks y notas metodológicas aplicadas a Marketing.

## Uso permitido

- referencias externas y bibliografía;
- Jobs To Be Done y otros frameworks como insumo metodológico;
- notas comparativas;
- síntesis aplicada a una campaña;
- enlaces hacia canónicos GTM/RevOps.

## Límite

Buyer persona, propuesta de valor, customer journey y otras definiciones corporativas no viven aquí como versiones paralelas. Su fuente canónica es:

`misaeln-pc1/capacita-global-control/docs/gtm-revops/`

Si una referencia externa cambia una definición corporativa, primero se documenta como evidencia o hipótesis y luego se propone el cambio mediante issue/PR en Global.

## No incluir

- copias completas de libros o material protegido;
- archivos pesados;
- información sensible;
- datos personales;
- canónicos GTM duplicados.
