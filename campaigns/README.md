# campaigns

Ejecución específica por campaña, canal, curso u objetivo comercial.

## Cada campaña debe contener

- brief u objetivo;
- baseline canónico GTM con IDs/versiones o documento/sección/versión;
- hipótesis publicitaria local;
- targeting táctico;
- mensajes y CTA por canal;
- destino y medición;
- aprendizajes agregados.

Usar como base:

- `../docs/GTM_CONSUMPTION_BRIDGE.md`;
- `../templates/CAMPAIGN_BRIEF_GTM.md`.

## Regla de propiedad

GTM/RevOps define buyer personas, propuesta de valor, journey y reglas comerciales transversales. La campaña selecciona, adapta y prueba una aplicación local sin redefinir esos conceptos.

## No incluir

- datos personales de leads;
- métricas sensibles exportadas sin anonimizar;
- archivos pesados de anuncios;
- credenciales o IDs completos de cuentas;
- campañas reales modificadas desde el repositorio;
- definiciones corporativas paralelas.
