# core

Índice de aplicación comercial reutilizable dentro de Marketing.

## Regla

La verdad corporativa de buyer personas, propuesta de valor, journey, segmentación, scoring, nurturing y touch strategy vive en:

`misaeln-pc1/capacita-global-control/docs/gtm-revops/`

Esta carpeta puede contener:

- índices hacia canónicos GTM;
- matrices de aplicación a campañas;
- convenciones locales de Marketing;
- aprendizajes agregados que todavía no cambian el canónico.

No debe contener:

- buyer personas o journeys paralelos;
- copias completas de canónicos sin necesidad;
- datos personales o exports CRM;
- credenciales, tokens o secretos.

Para campañas nuevas usar `docs/GTM_CONSUMPTION_BRIDGE.md` y `templates/CAMPAIGN_BRIEF_GTM.md`.
